Send to UFM Playground

A bookmarklet that sends the block labels on a page in the Umbraco backoffice to the UFM Playground: their real templates, and the real values from each block, so you can try out changes to a label against real content.

Send to UFM Playground ← Drag this to your bookmarks bar

Using it

  1. In the Umbraco backoffice (version 14 or later), open a document with a block list or block grid.
  2. Click the bookmarklet.
  3. If the page has more than one label template (e.g. several block types, or several block properties), choose one. The playground opens in a new tab with that label's template and a block for each block using it.

How it works

Every block label in the backoffice is rendered by an element which holds the label's template and the exact values Umbraco gives it, so the bookmarklet reads those, rather than calling Umbraco's API. Picked content, media and members are swapped from their keys to the names Umbraco has already looked up.

Nothing is sent anywhere: the values go to the playground in the URL's #hash, which browsers don't send to servers. But the link to the playground contains your content, so think before sharing it!

It reads parts of the backoffice which aren't a public API, so a future version of Umbraco could break it. It's tested against Umbraco .
