Embedding UFM previews

Include the script once, then use <ufm-preview> wherever you want a live preview of a UFM template, rendered by Umbraco's own UFM code. Back to the playground. 

<script type="module" src="https://ufm-playground.joe.gl/embed.js"></script>

A block label

<ufm-preview template="Call to Action: {umbContentName: page}" values='{"page": "Contact us"}'></ufm-preview>

Several blocks, with an editable template

Pass an array of values for several blocks. null means a property has never been set.

<ufm-preview template="${ heading || 'Untitled heading' }" values='[{"heading": "Contact us"}, {"heading": ""}, {"heading": null}]' editable playground></ufm-preview>

Placeholders

Leave out values (or some of them) and you'll get placeholder values, based on how the template uses each property.

<ufm-preview template="Text module: ${ truncate(stripHtml(bodyText), 35) } (${ $settings.flipped ? 'Flipped' : 'Not flipped' })" icon="icon-article"></ufm-preview>

Collection columns and property descriptions

<ufm-preview mode="collection" template="${ value ? '⭐ Featured' : '' }" values='[{"value": true}, {"value": false}]'></ufm-preview>
<ufm-preview mode="description" template="Use **Markdown** and [links](https://docs.umbraco.com) in descriptions"></ufm-preview>

Attributes

  • template: the UFM template.
  • values: JSON property values (plus $settings and $index), or an array of them for several blocks. Rich text is {"markup": "<p>…</p>"}; picked content is a name or array of names; links are [{"name": "…", "url": "…"}].
  • mode: block (default), collection or description.
  • icon: the block's icon, e.g. icon-article.
  • show-template: show the template above the preview.
  • editable: show the template, and let readers edit it, with the preview updating as they type.
  • playground: add an "Open in the UFM playground" link.
